# ShopSmart

ShopSmart is a full-stack e-commerce platform built to deliver a premium,
portfolio-style shopping experience with a modern React frontend and a
service-oriented Express + MongoDB backend.

## Problem Statement

Many student e-commerce projects focus only on CRUD functionality and miss the
parts that make a product feel real: a polished interface, clear architecture,
reliable testing, and deployment readiness. ShopSmart aims to combine all of
these into one cohesive submission.

## Target Users

- Customers who want to browse products, manage a cart, and place orders
- Admin users who manage categories and products
- Evaluators who need to inspect both design quality and engineering quality

## Core Features

- Browse products with category-aware filters and sorting
- Responsive cart experience with persistent local storage
- Category and product management APIs
- Order placement flow with payment metadata
- MongoDB-backed persistence through Mongoose models
- Docker, CI, and deployment configuration for DevOps evaluation

## Technical Direction

- Frontend: React + Vite
- Backend: Express + Mongoose
- Database: MongoDB
- Testing: Vitest, Jest, Supertest
- DevOps: GitHub Actions, Docker Compose, Render/Pages-ready config

## Expected Outcome

The final system should be easy to demo, easy to explain in a viva, and strong
across documentation, backend design, frontend polish, and deployment
readiness.
